# Portfolio plan

1. Stack: Vite + React + TypeScript, plain CSS tokens, no UI libraries (static output, Vercel).
2. Content is data: `src/content/*` (typed). Personal details come from `VITE_*` env vars (`.env.example`).
3. Visuals: editorial layout modelled on intercom.com (white and ivory bands, light grotesque headings, serif body, square markers); illustrations used sparingly; hero shows Dandelion screens in glass frames over a landscape; honours `prefers-reduced-motion`.
4. Quality: strict TS, ESLint, Vitest, GitHub Actions CI, semantic/accessible HTML, SEO meta.
5. Verify: lint, typecheck, test, build, visual check.

Sections: Hero, About (impact / nature / reading), Projects, Experience, Skills, Contact.
